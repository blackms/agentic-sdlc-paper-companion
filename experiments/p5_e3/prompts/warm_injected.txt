⚠️ **PATTERNS LEARNED FROM PRIOR REVIEWS — pay extra attention:**

The following bug patterns have been observed to be missed in prior review cycles. Check them carefully:

1. **off-by-one boundary errors** — `>` vs `>=`, `<` vs `<=`, n+1 / n-1 in indices, exponents, or loop bounds, off-by-one in range, slicing, exponent.
2. **logic errors** — inverted signs, swapped operators (+ vs −, * vs /), flipped conditions, wrong formula structure.
3. **currency mismatches** — case-sensitivity, missing currency check, hardcoded currency shortcuts, FX rate inversion.
4. **atomicity violations** — partial state updates, exception in middle of multi-step operation, write before validate, no rollback on error.
5. **exception-type errors** — wrong exception type (TypeError vs ValueError, RuntimeError, AttributeError, ImportError, etc.), assert masking validation.

For each of these pattern categories, look explicitly for instances. Don't just summarize the code — enumerate each case.
